## 1 软件概述

### 1.1 用途与适用对象

“秒算虾料软件（鸿蒙版）V0.1”（以下简称“本软件”）是一款运行于 HarmonyOS 的拌料计算工具，面向对虾养殖场的日常投喂管理。软件支持正算和反算：

- **正算**：按棚号录入当日各粒径饲料和发酵料的计划用量，自动计算每棚平均吃料量；
- **反算**：先确定或调整每棚平均吃料量，按棚数计算当天总饲料用量，再拆分到各料种，计算拌料加水量和每棚称料量。

本软件以“棚”为最小管理单元，适用于高位池、土塘、小棚等需要按棚称料的养殖场景。连续棚号可直接录入“1-40”“1到40”“1至40”；吃料量不同的棚可另起一行单独录入。换料期间可设置细粒径料与粗粒径料的比例，按比例拆分小料和大料各自用量。软件不要求联网，也不要求注册账号。

### 1.2 主要功能

- 棚号区间与多段棚号录入，自动推算棚数，支持 30 行数据；
- 第 1 行作为整组剩余棚数，第 2 行起可抽出特殊棚组，第 1 行自动扣减；
- 平均吃料量支持正算和反算；
- 按全局含水率自动计算加水量，按棚数折算每棚称料量；
- 拌料参数：含水率 10%～40%，发酵料是否参与算水、是否参与算料；
- 换料比例 10%～90%，细料清空时自动并入粗料；
- 列固定、隐藏、显示；手机端快捷设置，平板端长按表头；
- 手机锁竖屏；平板自动旋转，横屏/竖屏都按当前窗口宽度重新分配 11 列，启动即全屏；
- 简体中文/英文切换，数据与语言设置分别保存；
- 数据本地自动保存、退出恢复、一键重置；
- 标题栏误差提示、底部统计行、内置帮助、隐私政策与用户协议。

### 1.3 软件特点

1. **现场操作简单**：大单元格、自绘表格，点击即可编辑；键盘“下一步”可连续录入；棚号支持区间写法。
2. **计算口径清晰**：平均、加水、称料和换料合并都有固定公式，第 10 章逐项列出并给出示例。
3. **数据留在本机**：不声明网络权限，不采集、不上传个人信息；数据保存在应用私有 `preferences`。
4. **适配手机与平板**：手机固定列宽、横向滚动；平板自动旋转，11 列按当前窗口宽度均分，横竖屏都铺满。
5. **启动即全屏**：平板通过 `supportWindowMode: ["fullscreen"]` 直接全屏启动，不出现自由窗口。

### 1.4 使用流程

1. 启动软件，首次使用时阅读并同意隐私政策与用户协议；
2. 第 1 行录入整组棚号，后续行抽出吃料偏慢、偏快或用料不同的特殊棚组；
3. 按需设置换料比例；录入各粒径料和发酵料用量，或填写每棚平均吃料量；
4. 核对平均、各料量、加水量、称料量和标题栏误差；
5. 按统计行汇总拌料，收工前记录或截图保存。

## 3 安装与启动

### 3.1 安装

- **云调试/测试**：将 release 签名的 `.hap` 上传到 AGC 云调试，选择 MatePad 等设备安装；
- **正式发布**：将 release 签名的 `.app` 上传到 AppGallery，审核通过后由应用市场安装。

安装前请确认设备系统不低于 HarmonyOS 6.0.1（API 21）。软件不要求登录，也不要求插入电话卡。

### 3.2 首次启动

首次启动时，主界面上方弹出“隐私政策与使用协议”窗口，展示条款摘要，并提供“隐私政策”“用户协议”两个可点击链接。点击“同意”进入主界面；点击“拒绝”退出应用。

同意状态按 `privacy_version` 记录。条款版本升级后，老用户会再次被要求确认。若条款文案读取失败，软件提示加载失败并退出，不会在未展示条款的情况下放行。

### 3.3 主界面

主界面由标题栏、表格区和底部统计行组成：

- 标题栏左侧为菜单按钮，中间显示“养虾拌料计算器”，右侧显示误差值；
- 表格区为 30 行、11 列的自绘表格；
- 统计行位于表格底部，随数据实时更新；
- 绿色标题栏、白色表头、白底数据行；棚数为 0 的禁用格显示浅灰。

启动后软件读取上次保存的数据并恢复表格。首次使用时 30 行为空，序号显示 1～30，统计行显示 0。点击任一可编辑单元格即可开始录入。

## 4 界面与字段说明

### 4.1 表格结构

表格自上而下分为表头行、数据行和统计行。表头行白底黑字，列名固定；“发酵料”表头会按设置显示浅绿色或棕色粗边框。数据行为 30 行，序号 1～30；统计行位于底部，随数据变化实时刷新。

表格由一个 `MixCalcTable` 组件统一绘制，支持横向滚动、纵向滚动、固定列和单元格编辑浮层。序号列底部显示“已填行数/30”；纵向滚动时表头和统计行保持可见；横向滚动时固定列停在左侧。

平板端按当前窗口宽度均分 11 列；手机端使用固定列宽并允许横向滚动。

### 4.2 字段说明

| 列名 | 可编辑 | 说明 |
| --- | --- | --- |
| 序号 | 否 | 行号 1～30，底部显示已填行数/30 |
| 棚号 | 是 | 棚号或棚号区间，支持多段录入 |
| 棚数 | 是 | 由棚号自动推算，也可手动修改 |
| 平均 | 条件可编辑 | 每棚平均吃料量，默认自动计算 |
| 发酵料 | 是 | 该行发酵料总量 |
| 粉料 | 是 | 该行粉料总量 |
| 0.3料 | 是 | 该行 0.3 粒径料总量 |
| 0.5料 | 是 | 该行 0.5 粒径料总量 |
| 1.0料 | 是 | 该行 1.0 粒径料总量 |
| 水 | 否 | 按含水率自动计算的加水量 |
| 称料 | 否 | 按棚数折算的每棚称料量 |

可编辑单元格获得焦点后弹出编辑框和数字键盘。提交方式：键盘“下一步”、点击编辑框外区域、系统返回键。提交后立即重算并保存。

### 4.3 统计行

- 棚数、发酵料、粉料、0.3料、0.5料、1.0料、水：对各数据行求和；
- 平均：只统计行平均大于 0 的行，按各行棚数加权，`Σ(行平均×棚数) ÷ Σ棚数`；平均为 0 的行整行不参与平均，其棚数也不进平均分母；
- 序号：显示已填行数/30；
- 棚号列底部：“帮助”按钮，打开内置使用帮助；
- 称料列底部：“重置”按钮，弹出重置确认框。

统计行数值为整数时显示整数，非整数保留两位小数。统计行“棚数”一格仍显示所有行棚数之和。

### 4.4 标题栏与菜单

标题栏右侧显示误差值：把每行“发酵料+粉料+0.3料+0.5料+1.0料+水”求和，再与“称料（保留两位小数）×棚数”求和相减。绝对值小于 0.005 时留空；否则显示带正负号的两位小数。

菜单包含：快捷设置（仅手机）、批次切换、隐私政策、用户协议、使用帮助、选择语言、版本号。平板隐藏“快捷设置”，列设置通过长按表头完成。

## 5 基础操作

### 5.1 棚号录入

点击棚号单元格，弹出编辑框和数字键盘；输入完成后提交。支持：

- 连续区间：`1-40`、`1到40`、`1至40`、`1~40`、`1—40`、`1号到40号`；
- 单个棚号：`12`；
- 多段组合：`1-10 15-20 25`；
- 分隔符：英文逗号、中文逗号、顿号、空格。

区间按“首号到末号”计算棚数，降序区间按绝对值计算，例如 `40-1` 与 `1-40` 都计 40 棚。软件不对重复区间去重：同时录入 `1-10` 和 `5-8` 时按 `10+4=14` 棚计算。非数字内容会被忽略；无法识别为区间的片段按 0 棚处理。

### 5.2 棚数计算与首行规则

棚数默认由棚号自动推算，也可点击棚数单元格手动修改。手动修改后，再改棚号不会覆盖手改值；把棚数改为 0 并提交，可恢复自动推算。

实际使用时，通常先在第 1 行录入整组棚号（例如 1-40），从第 2 行起把吃料偏慢、偏快或用料明显不同的棚单独抽出。第 1 行自动扣减这些已抽出的棚数，代表剩余棚。

第 1 行棚数 = 第 1 行基数 − 第 2～30 行棚数之和。例如第 1 行录入 1-32，第 2 行录入 5-8，则第 1 行显示 28 棚，该行料量按 28 棚计算。若希望第 1 行按 32 棚计算，不要在下面重复录入 5-8。

第 1 行棚数允许为 0 或负数，以便提示差异。第 1 行棚数变化时，软件保持该行“每棚平均”不变，按新棚数重算料量、水量和称料；普通行则是料量不变、平均随棚数变化。

### 5.3 平均吃料量

平均列默认自动计算：

```text
平均 =（粉料 + 0.3料 + 0.5料 + 1.0料 + 参与算料的发酵料）÷ 棚数
```

棚数为 0 时平均为 0。发酵料是否参与算料由第 6.2 节设置决定。

满足以下条件时平均列可手动填写：棚数大于 0；非发酵料中只有 0、1 或 2 种有数值；整行不能只有空值。手动填写后，软件把“平均×棚数”作为总料量，按现有料种和换料比例反算到各料格；加水量和称料随之重算。非发酵料有 3 种及以上时平均列只读。

手动修改任意料格或发酵料后，平均列恢复自动计算。手动平均不会改变棚数，也不会改变发酵料设置。

### 5.4 料量录入

发酵料、粉料、0.3料、0.5料、1.0料均可点击编辑，支持整数和两位以内小数。输入 0 或清空表示该料种不用。普通行必须先有棚数才能编辑料格；棚数为 0 时料格禁用。

键盘右下角为“下一步”，提交后跳到本行下一个可编辑单元格；行末换行。修改料格会取消该行已设置的换料比例。

## 6 拌料参数

### 6.1 含水率

点击表头行“水”单元格，弹出含水率列表：10%、15%、20%、25%、30%、35%、40%。选择后立即按新比例重算所有行水量和称料，并保存为全局设置。表头显示为“水20%”形式，默认 20%。

水量计算基数默认是粉料、0.3料、0.5料、1.0料之和；若设置发酵料参与算水，则再加上发酵料。

### 6.2 发酵料设置

点击表头行“发酵料”单元格，弹出“发酵料计算设置”窗口，包含两个独立选项：

| 选项 | 作用 |
| --- | --- |
| 参与算水 | 水量基数包含发酵料 |
| 不参与算水 | 水量基数不包含发酵料，但称料仍包含发酵料 |
| 参与算料 | 平均吃料量的分子包含发酵料 |
| 不参与算料 | 平均吃料量的分子不包含发酵料 |

两项都是全局设置，对所有行生效；默认均不参与。设置保存在本地，下次启动继续生效。

### 6.3 换料比例

换料比例用于两种粒径饲料过渡：把一行非发酵料总量按比例拆成“细料”和“粗料”两档。长按目标料格，弹出 10%～90% 的比例列表，当前比例以“✓”标记。

可长按的目标格：该行恰好有两种非发酵料时，为粒径较大的那一格；只有一种非发酵料时，为该格的“大一号”料格（可为空）。比例表示较大粒径料占非发酵料总量的百分比，范围 10%～90%，步长 10%。

设置后该行每棚平均保持不变，料量按比例重新分配；水量和称料重算。手动修改任意料格或发酵料后，换料比例自动作废。

### 6.4 换料完成

当一种细粒径料用完、只剩一种更粗的料时，可以手动清空细粒径料单元格，软件自动合并：把清空前细料数值并入唯一粗料格，细料格清零，换料比例作废，并提示“换料完成”。

合并需要同时满足：被清空的格是细粒径料；该行除它以外只有一种非发酵料，且粒径更粗；清空前该格数值大于 0。若有更细的料有数值，或存在两种更粗的料，则不合并。

合并使用进入编辑前的原值，因此逐字退格到空也能正确合并；合并前后该行料量总量守恒。

### 6.5 换料参数核对

换料前建议核对：目标粒径是否为计划使用的下一档；该行非发酵料是否只有两种；比例方向是否为“较粗料占比”；拆分后的总量是否与当日计划一致。设置比例后观察平均列，正常情况下平均不变，只有料量在两种粒径间重新分配。

## 7 表格视图

### 7.1 列操作

长按任意表头单元格，弹出列操作菜单：固定此列/取消固定、隐藏此列/显示此列、显示所有列、取消所有固定。菜单标题显示“列操作 - 列名”。

固定列始终排在未固定列前面，并保持原有顺序；隐藏列不参与绘制，但保留数据。列状态保存在本地，下次启动恢复。

### 7.2 快捷设置（仅手机）

手机端点击菜单→快捷设置，打开列设置面板。面板列出棚号、棚数、平均、发酵料、粉料、0.3料、0.5料、1.0料、水共 9 列，每列提供固列、解固、隐列、显列四个开关。底部提供全取消、全解固、列全显、全确认。

平板端不显示“快捷设置”菜单项，可直接长按表头操作。序号列和称料列未纳入快捷设置，避免误隐藏关键信息。

### 7.3 平板自适应与全屏

- 手机：锁定竖屏，固定列宽，横向滚动；
- 平板：自动旋转，横屏/竖屏都按当前窗口宽度重新分配 11 列；
- 平板启动即全屏：`supportWindowMode: ["fullscreen"]`，不出现自由窗口；
- 横屏时窗口宽、高度矮，11 列仍按宽度铺满；纵向可滚动的行数减少；
- 键盘弹出时统一使用 `KeyboardAvoidMode.RESIZE`，页面压矮，表尾始终在键盘上方。

### 7.4 滚动与固定

表格支持横向滚动和纵向滚动。固定列在横向滚动时保持可见；未固定列随手指移动。纵向滚动到边界时回弹；点击单元格进入编辑，编辑框跟随单元格位置显示。表格使用单一组件自绘，不创建大量子组件，适合 30 行 × 11 列规模。

## 8 数据与统计

### 8.1 自动计算

每次提交单元格、切换含水率、修改发酵料设置、设置换料比例或重置后，软件按以下顺序重算：

1. 更新各普通行的棚数和派生值；
2. 重算第 1 行剩余棚数；
3. 重绘表格、刷新统计行并保存。

普通行：

```text
棚数 = 棚号推算值（手改则用手改值）
平均 = 总料量 ÷ 棚数
水   = 参与算水的料量 × 含水率
称料 =（全部料量 + 水）÷ 棚数
```

第 1 行：`棚数 = 基数 − 后续行棚数之和`；棚数变化时锁定每棚平均，反算料量。

### 8.2 汇总与误差

底部统计行实时汇总棚数、发酵料、粉料、0.3料、0.5料、1.0料、水；平均列按参与行棚数加权；称料列显示重置按钮，不显示合计。

标题栏右侧误差值 = 配料合计 −（称料（两位小数）× 棚数）之和。误差为 0 或绝对值小于 0.005 时不显示；有差异时显示正负号，最多 5 个字符。误差通常来自称料四舍五入、漏填料量或棚数不符。

### 8.3 本地保存

每次数据变更后，软件把 30 行数据序列化为 JSON，写入应用私有 `preferences`（`MixCalcPrefs`）。保存内容包括棚号、棚数、基数、平均、各料量、水量、称料、手改标记和换料比例；全局设置保存含水率、发酵料两项开关、隐私同意版本和列状态。

启动时读取本地数据并恢复表格。数据只在本机保存，不上传服务器；卸载或清除应用数据会删除全部记录。软件不提供云同步和跨设备迁移。

### 8.4 重置

点击表格底部“称料”列的“重置”按钮，弹出确认框。已有数据时提示“当前已有 N 行数据，重置后将全部清空”；没有数据时提示“当前没有数据需要重置”。确认后清空 30 行数据并提示“所有数据已重置”；不改变当前含水率和发酵料设置。

## 10 计算规则

### 10.1 棚号解析

软件先统一分隔符：中文逗号、顿号、空格均作为分段；每段若包含 `-`、`到`、`至`、`~`、`—`，按区间处理：把中文符号替换为 `-`，去掉“号到/号至”，以第一个 `-` 分成首尾两段，去掉非数字字符后转整数。首尾都大于 0 时：

```text
棚数 = |末号 − 首号| + 1
```

非区间段去掉非数字字符后仍有数字，则计 1 棚；否则计 0。所有段求和后取不小于 0 的值。

| 输入 | 棚数 | 说明 |
| --- | --- | --- |
| `1-40` | 40 | 连续区间 |
| `1到40` | 40 | 中文“到” |
| `40-1` | 40 | 降序，按绝对值 |
| `1-10 15-20 25` | 16 | 10 + 6 + 1 |
| `1-10,5-8` | 14 | 分段分别计数，不去重 |
| `A棚` | 0 | 没有数字 |

### 10.2 平均吃料量

```text
平均 = (F粉 + F0.3 + F0.5 + F1.0 + [F酵]) ÷ N棚
```

方括号表示“发酵料参与算料”时加入；`N棚` 为 0 时平均为 0。默认发酵料不参与算料。

手动平均时：

```text
总量 = 平均 × 棚数
```

若发酵料参与算料且大于 0，先扣除发酵料；剩余量按非发酵料种类拆分：0 种时全部给发酵料；1 种时全部给该料；2 种时按换料比例拆分，未设置比例则按两料现有值占比拆分；比例限制在 10%～90%。

### 10.3 加水量

```text
水 = (F粉 + F0.3 + F0.5 + F1.0 + [F酵]) × p
```

`p` 为含水率，取值 10%～40%，步长 5%。发酵料是否进入括号由“参与算水”开关决定。

### 10.4 称料量

```text
称料 = (F粉 + F0.3 + F0.5 + F1.0 + F酵 + 水) ÷ N棚
```

发酵料无论是否参与算水，都计入称料总量；棚数为 0 时称料为 0。显示时整数不带小数点，非整数保留两位小数。

示例：含水率 20%，发酵料不参与算水、不参与算料。

| 行 | 棚号 | 棚数 | 平均 | 0.3料 | 水 | 称料 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 1-28 | 24 | 5.00 | 120 | 24.0 | 6.00 |
| 2 | 25-28 | 4 | 6.00 | 24 | 4.8 | 7.20 |
| 统计 | — | 28 | 5.14 | 144 | 28.8 | — |

第 1 行录入整组 1-28，第 2 行抽出 25-28 这 4 棚吃料偏快的棚，所以第 1 行显示 24 棚。统计行平均按棚数加权：`(5.00×24 + 6.00×4) ÷ (24+4) = 144 ÷ 28 ≈ 5.14`。

### 10.5 第 1 行锚点规则

设第 1 行棚号推算的基数为 `B`，后续行棚数之和为 `S`，则：

```text
R = B − (S − S0)
```

`S0` 是手动修改第 1 行棚数时记录的后续行棚数之和；未手改时 `S0=0`，即 `R=B−S`。

手改第 1 行棚数时，把修改后的显示值作为新基数，并记录当时后续行棚数之和；之后后续行增减，只按增量扣减，不重复扣除。例如手改 32→28、第 2 行有 3 棚时第 1 行显示 28；第 2 行改为 5 棚时第 1 行显示 26，而不是 23。

第 1 行棚数变化时，若原平均大于 0 且平均未被手动修改，软件锁定原平均，按新棚数反算料量。

### 10.6 换料完成合并

设被清空的细料下标为 `i`，清空前原值为 `A`。软件从粉料、0.3、0.5、1.0 中查找其他有值的非发酵料：

- 若存在下标小于 `i` 的料，说明还有更细的料，放弃合并；
- 若除 `i` 外有值的料不是恰好 1 个，放弃合并；
- 否则把 `A` 加到该粗料上，把 `i` 清零，换料比例置 0，并提示“换料完成”。

合并后总量不变：`A + 粗料原值`。合并使用进入编辑前的原值，避免逐字退格导致数值被改小。

### 11.3 数据流

触摸事件由 `MixCalcTable` 命中测试确定行、列和单元格矩形；点击进入编辑，编辑框定位到单元格；提交时更新对应 `FeedData` 字段。

随后进入统一重算出口：普通行调用 `updateAllCalculations`，第 1 行调用首行锚点重算；再刷新统计行、保存数据、触发重绘。重绘时先画表头，再按可见列和固定列顺序画数据行，最后画统计行。

固定列与滚动列分别计算位置：固定列从左侧按顺序排列，滚动列加横向偏移并裁剪；纵向滚动使用偏移量和惯性滑动，表头与统计行保持可见。

### 11.4 本地存储

`preferences` 文件名为 `MixCalcPrefs`。主要键包括：批次数据、当前批次、含水率、发酵料两项开关、隐私同意版本、列可见性/固定状态、语言偏好。

每行数据包含棚号、棚数、基数、平均、发酵料、粉料、0.3料、0.5料、1.0料、水、称料、手改标记和换料比例。启动时读取并恢复。

## 12 异常提示与常见问题

### 12.1 提示信息

| 提示 | 触发场景 | 处理建议 |
| --- | --- | --- |
| 隐私政策与使用协议加载失败 | 首次启动读取条款失败 | 重新打开应用 |
| 设置未改变 | 重复选择相同发酵料设置 | 无需处理 |
| 换料完成 | 细料并入粗料 | 核对合并后的料量 |
| 水百分比已设置为 N% | 选择含水率成功 | 无需处理 |
| 列已固定/取消固定 | 列操作成功 | 无需处理 |
| 列已隐藏/显示 | 列操作成功 | 无需处理 |
| 列设置已保存 | 快捷设置确认 | 无需处理 |
| 所有数据已重置 | 确认重置成功 | 重新录入 |

### 12.2 常见问题

1. **料格点不动、不能输入**：普通行棚数为 0 时料格禁用。先填写棚号或手改棚数，再录入料量。
2. **棚数和手算不一致**：检查第 1 行剩余规则、是否重复录入区间、棚数是否被手改。把棚数改为 0 可恢复自动推算。
3. **平均列不能修改**：非发酵料有 3 种及以上，或整行为空时平均列只读。减少料种或先填料量。
4. **长按料格没有换料比例**：只有目标格才会弹出比例列表；两种非发酵料时为较粗一格，一种时为它的“大一号”格。
5. **清空细料没有提示换料完成**：可能还有更细的料有数值、存在两种更粗的料，或清空前原值为 0。
6. **统计行平均和总料÷总棚不完全一样**：平均只统计行平均大于 0 的行；没填料或只有发酵料且未参与算料的行不计入平均，其棚数也不进平均分母。
7. **标题栏出现数字**：这是配料合计与称料折算的误差。检查四舍五入、漏填和棚数。
8. **换手机或重装后数据没了**：数据只保存在本机；卸载或清除应用数据会删除记录，软件不提供云同步。
9. **没有网络能用吗**：能。软件未申请网络权限，全部计算在本机完成。
10. **料量可以用斤吗**：可以。软件不换算单位，同一表格内保持统一即可；含水率按百分比计算，与料量单位无关。
11. **平板横屏时为什么列变宽了**：平板按当前窗口宽度重新分配 11 列；横屏窗口宽，列宽随之变大，属于自适应。
12. **平板启动为什么不是小窗口**：软件配置了 `supportWindowMode: ["fullscreen"]`，启动即全屏；若仍是小窗口，检查安装包是否为新版本。

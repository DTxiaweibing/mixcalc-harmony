# 应用市场更新说明（0.3.6 → 0.3.7）

> 用途：华为 AGC「版本更新说明」填写。简单版用于更新列表 / 弹窗，详细版用于版本详情页，按字数限制取用。
> 定稿：2026-11-14（与 `CHANGELOG.md` 的 0.3.7 条目一一对应）。

## 一、简单版（约 280 字，推荐直接用）

0.3.7 修的都是日常用久了才会碰上、但一碰上就影响算料的问题：

1. 一行棚号全删光后，离开这一格（点别处、按下一行、按回车都算），这行会马上收起来，下面的行上顶，底部补一行空行，中间不再留空档。
2. 输入超上限之类的提示，现在固定显示在表头那一行，不再忽高忽低压在两栏交界处。
3. 所有提示统一成同一种样式（浅红底、深红字），两秒左右自动消失，不影响您点表头。
4. 手机上点棚数气泡右上角的「⋮」菜单不再占掉大半个屏幕，收窄到约三分之一屏宽；平板 11 列全显示时宽度不变。
5. 帮助页里的棚号上限由 1000 改正为实际的 99；菜单里的版本号也显示对了。

## 二、详细版（约 620 字）

**删空棚号后，行一定收得回去**

- 以前只有「删号码气泡」和「转入」这两条路会让整行回收；直接清空格子再点别处、按下一行、按回车、换格编辑这几种离开方式都漏了判断，于是出现「棚号和棚数都空了，这行还赖着不走，下面几行也不上顶」。
- 现在这四种离开方式一律按同一套判据结算：编辑前有号、编辑后棚号为空且棚数为 0，就判定为删空，整行回收、下面的行上顶、底部自动补一行空行，总行数不变。
- 填过料的行不受影响（本来就按有无内容回收），所以以前是「时好时坏」，现在行为一致。

**提示更清楚、位置更稳**

- 输入超上限、隐私文案加载失败、整行转到空行等提示，原来用的是系统提示条，位置靠偏移量估算，机型不同就会漂，常见是正好压住标题栏和表头的交界。
- 现在统一改为页内的胶囊提示：高度与表头行一致、正好盖在表头这一行上，两端半圆，浅红底深红字；英文长句自动缩小字号，尽量一行放下。
- 提示约两秒自动收起，并且不会挡住表头点击，输入时也不会抢走焦点。

**手机上更好点**

- 棚数气泡右上角「⋮」菜单里的「全选 / 反选 / 删除 / 转出」，原来宽度跟着气泡走，手机上一撑就是大半屏；现在手机按屏宽的三分之一收窄，平板 11 列铺满时保持原来的宽度。
- 菜单里显示的版本号以前是写死的，升级后还停在旧号；现在直接读安装包版本，装哪个版本就显示哪个版本。

**说明与管理修正**

- 中英文帮助页与更新说明里的棚号上限由 1000 改正为 99（实际代码上限一直是 99，输入超过会提示且不计入）。

## 三、一句话版（不超过 40 字）

删空棚号后行立即回收，提示压表头并统一样式，手机「⋮」菜单收窄。

# 应用市场更新说明（0.3.4 → 0.3.5）

> 用途：华为 AGC「版本更新说明」填写。以下三段可分别用于「本次更新」「更新亮点」「详细说明」，按字数限制取用。

## 一、简短版（约 80 字，适合列表页）

本次更新优化了大屏与折叠屏体验：快捷设置面板改为铺满窗口，表格铺满 11 列时自动收起该入口；表头弹窗不再超出屏幕；折叠屏按当前窗口宽度自动切换手机/平板布局；修复了启动闪图标、横屏启动后抽屉菜单过宽的问题，并补充了英文界面的帮助、隐私政策与用户协议页面。

## 二、分条版（适合版本详情页）

**新增**

- 英文界面下，「使用帮助」「隐私政策」「用户协议」现在显示英文版页面（此前固定显示中文）。

**优化**

- 快捷设置（列管理）面板左右铺满当前窗口，不再有右侧空白；折叠 / 展开 / 分屏 / 转屏后跟随窗口变化。
- 表头弹窗（水比 / 发酵料 / 列操作）改为右边缘对齐所点单元格，靠边时自动夹回屏幕内，不再向右溢出。
- 折叠屏与平板改为按**当前窗口宽度**切换布局：内屏 / 横屏铺满 11 列，外屏 / 单屏态自动回到手机布局（固定列宽 + 横向滚动）。

**修复**

- 启动时不再闪现应用图标与白屏，启动页底色与表格背景一致，首帧直接出界面。
- 手机横屏状态下启动后，抽屉菜单宽度错误（约为屏幕宽度的 3/4）的问题；现在始终按竖屏窗口宽度计算（约 1/3 屏宽）。
- 手机方向在页面加载前即锁定为竖屏，不再出现「先横后竖」的翻转。
- 表格已铺满 11 列时，菜单不再出现无意义的「快捷设置」入口；只要有列被隐藏，入口一定保留。
- 窗口尺寸 / 形态变化时，已打开的主菜单、批次子菜单、快捷设置、语言弹窗和贴表头弹窗会自动关闭，不会停留在旧位置。

## 三、一句话版（不超过 30 字）

折叠屏与平板布局优化，修复启动闪屏与菜单宽度，补充英文帮助与协议页面。

## 备注

- 版本号：`0.3.5`（versionCode `1000305`），不涉及数据格式变更，覆盖安装即可，本地批次数据保留。
- 与安卓 0.3.5 功能对齐。

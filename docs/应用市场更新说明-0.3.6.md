# 应用市场更新说明（0.3.5 → 0.3.6）

> 用途：华为 AGC「版本更新说明」填写。简单版用于更新列表 / 弹窗，详细版用于版本详情页，按字数限制取用。

## 一、简单版（约 150 字，推荐直接用）

0.3.6 这次把棚号彻底重做了，填棚号更省事，也不会再算错料：

1. 棚号一改，棚数、料量、水量自动跟着重算，不会再用老数据算料。
2. 多行棚号有重叠时自动让号，同一个棚只算一遍，料不会算两遍。
3. 点「棚数」能看本行全部棚号，可勾选后转到别的行；转错了把目标行清空，号码会自动退回。
4. 删号码前会告诉您：哪些退回上面几行继续算料，哪些是真的删掉。
5. 棚号被清空的行自动回收，表格不留空档，底部自动补一行。

## 二、详细版（约 450 字）

**棚数和料量更准**

- 改棚号就等于改棚数：每行棚数按本行棚号实际占有的个数算，料量、水量、称料一起重算，每棚平均用料保持不变。
- 多行棚号有重叠时，同一个棚只算一遍，归最后填写的那一行，前面几行自动让出，重叠棚不会把料算两遍。
- 棚数格改为只读，由棚号自动算出来，不用再手填，也不会填错。

**棚号看得更清楚**

- 棚号格改为两行显示：一行最多 9 个字，最多两行，1-40 这种连续区号不会从中间切断；放不下时只省略中间，首尾关键号一定露出来。
- 字号加大并固定，不随手机字体大小变化；棚号列也加宽了，长号码能完整看清。

**新增棚号气泡：能点、能选、能转**

- 点「棚数」弹出本行全部棚号，点一下就选中，支持全选、反选。
- 选中的棚号可以转到别的行：先转出，再到目标行点「棚数」→「转入」即完成，往上转往下转都行。
- 转错了不要紧：把目标行的棚号清空，号码会自动退回原来那行继续算料，不会凭空消失。

**删除和整理更放心**

- 删号码前先判来路：本来是从上面几行退下来的，删掉就退回那些行继续算料；别的行都没写过它，才是真删除。确认框会分别说清，真删的号码会点名列出。
- 一行棚号被清空后整行自动回收，下面的行自动上顶，底部补一行新空行，表格中间不留空档，总行数不变。
- 棚号上限 1000，输入超出会提示，超出部分不计入，改回合法值后自动接着算。

## 三、一句话版（不超过 40 字）

棚号大升级：自动算棚数、重叠不重复算，气泡可勾选与转出转入，空行自动回收。

## 备注

- 版本号：`0.3.6`（versionCode `1000306`），功能水平对齐安卓 0.3.20。
- 不涉及数据格式变更，覆盖安装即可，本地批次数据保留。
- 本次在鸿蒙端属于新增能力（0.3.5 只有棚号文本与手填棚数），文案按「新增」口吻写；安卓端 0.3.5 已有棚号气泡，对应文案用「升级」口吻（见安卓仓库 `docs/应用市场更新说明-0.3.6.md`）。

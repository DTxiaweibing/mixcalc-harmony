- **用 Python 纯标准库解析 DevEco SDK 自带 `HarmonyOS_Sans.ttf` / `HarmonyOS_Sans_SC.ttf` 的 cmap+hmtx**（unitsPerEm=1000），advance @14vp：`…`=1000u=14.00vp、`‥`=1000u=**14.00vp（完全等宽，一点不省）**、`․` gid=0（**该字体缺字，会 fallback**）、ASCII `.`=231u=3.23vp、`·`=500u=7.00vp、`0`=570u=7.98vp、`-`=488u=6.83vp、空格=270u=3.78vp。两份字体结果一致。
